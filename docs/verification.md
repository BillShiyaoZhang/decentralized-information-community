## Runtime 0.3.0

- `npm test` 143/143 通过，较 0.2.0 新增 23 项；数据校验、构建与 `npm run package:runtime` 通过，生成 core 0.2.0 与 runtime 0.3.0 固定 tgz。
- 账户测试覆盖具名离线操作员要求、严格输入/白名单输出、密码与 TOTP 分别或共同替换、目标全部会话及幂等记录失效、其他账户保留、版本冲突与失败审计回滚。密码单独更新及等价 Base32/HMAC 密钥均不能使已用 TOTP 重放。
- 实际 HTTP 登录验证新凭据成功、旧密码/旧 TOTP/旧会话失败；角色调整、普通停用及重新启用与永久撤销分离。四种离线维护动作分别发生在已开始的发布请求体上传期间，后续写入全部被拒绝。匿名、邀请身份和具名 HTTP 客户端均无凭据维护入口。
- 旧 auth schema 1 数据库原子升级为 2，保留活跃账户、会话与审计，旧停用账户保守成为永久撤销；旧备份迁移后清空全部内置凭据并要求当前撤销登记，未知永久撤销 ID 也保留。迁移/恢复失败不修改目标库，成功后不能仅靠启用状态解锁账户。
- 仓库外实际包通过标准 CLI 为同一 actor ID 轮换凭据，验证原发布审计归属保留、旧凭据失效、具名维护审计及不含秘密的输出；缺少操作员、无效私有 JSON 和重复旧版本命令失败且不泄漏秘密。恢复后新凭据完整重新引导并登录成功；配置、业务数据和页面在合成 0.3.1 升级测试中保留，该版本仅为 fixture。
- 指定未兑换邀请取消覆盖 MFA 授权、单张取消、重复取消、已兑换/过期拒绝与失败事务回滚；同主体其他设备、资格和邀请保持有效。
- 本轮未修改 UI，未推送 GitHub、关闭 issue 或发布 registry。
