在 https://github.com/BillShiyaoZhang/QandA 项目中，我们尝试构建了一种去中心化的信息填充机制。即，用户创建话题、用户填充话题信息、话题与信息相互联结形成一张网、网中的信息可以检索。更好的是，这些内容不仅可以在私有服务器上做复杂计算，甚至可以利用 GitHub page 这样的静态网页服务实现基本的功能。

我想这套机制值得一个更好的设计，以让它真正容易被再次使用，并通过开源鼓励这种模式。对我自己来说，像 https://github.com/BillShiyaoZhang/xjtlu-unofficial-guide 这样的项目如果利用此项目作为基础进行开发，也会方便很多，只需要实现业务层面的内容就好。

这个项目应该同时保留私有服务器上的强大计算可能性，也要能通过 GitHub page 提供基础、快速的部署服务以便使用这个项目的产品能够快速迭代。

另外，ontology（作为蓝图）和 knowledge graph（作为实际数据的抽象）也许应该被用在项目中（如果有帮助的话）。

使用 docker 开发，以方便迁移。构建项目文档，以方便它人使用。
